# Ice 的宇宙探索 (ICE)

仓库：`https://puni.sh/api/repository/ice`

欢迎使用这款月球插件，它能把月球上那套令人头疼的重复劳作变成可以自动化、也简单得多的流程。  
它的总体目的是帮你重抽并刷取特定的宇宙探索任务。无论你想把每个任务都刷到金星来拿到那个称号，还是刷宇宙工具研究数据来获得你的能工巧匠/大地使者工具。又或者你正在给每一个职业刷到 50 万点。

<img width="621" height="394" alt="image" src="https://github.com/user-attachments/assets/722c3e44-74d2-49d3-964a-de21e6a2cf87" />

功能：  
✔️ 重抽，直到刷出你想刷的任务  
✔️ 通过“宇宙工具研究数据刷取”自动挑选最优任务，找到符合你宇宙工具研究数据需求的任务，帮你完成那些工具  
✔️ 选择你希望在哪个评价档位汇报任务（铜星、银星、金星），以决定你希望何时汇报  
✔️ 可通过“优先刷取”模式设置想优先刷的职业，并为天气限定/时间限定/连续任务循环切换职业与任务类型

依赖需求：
### 制作
- Artisan | 仓库：`https://github.com/PunishXIV/Artisan`

### 钓鱼
- AutoHook | 仓库：`https://github.com/InitialDet/AutoHook`
- 如何自动接受收藏品：`https://github.com/PunishXIV/AutoHook/blob/main/AcceptCollectable.md`

### 采集
只需要寻路（navmesh）
- Vnavmesh | 仓库：`https://github.com/awgil/ffxiv_navmesh`

插件内有一个窗口会详细说明各类需求，如果你还没安装对应插件，它还会提供安装按钮。
